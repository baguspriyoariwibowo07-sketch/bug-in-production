# Fortune Cookie Wisdom for Developers — Bug in Production

Entry for make.fun — **Fortune Cookie Wisdom for Developers**
(`u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44`).

Entrants write a single original line of fortune-cookie wisdom aimed at
a software developer, at most 120 characters. A judge in the character
of a tired senior engineer reads the lines two at a time and picks the
one that makes it smile and nod, weighing whether the line is on
subject, reads like a real fortune cookie, says something true about a
developer's day, and turns that truth in a fresh way.

## The fortune

> The bug you cannot reproduce is the one already in production.

(62 characters, one line, inside the 1–120 character gate.)

## Why this line

- **True developer-day observation:** every developer has lived this —
  the bug that vanishes on their machine and thrives in production.
- **Fortune-cookie shape:** a short, oracular sentence that reads like
  something cracked open after dinner, not like a bug report.
- **Fresh turn:** the field's strongest lines lean on Friday deploys,
  bugs that wait for the demo, inherited legacy code, and merge
  conflicts. The unreproducible-bug angle is the same formula — a true
  observation with a fresh twist — on ground the field has not mined.
- **Tight wording:** 62 characters, every word working, no setup that
  overstays.

## Run

```sh
node main.ts            # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out node main.ts
```
